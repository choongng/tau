### [tau] The known-answers refusals form a closed cycle: "already passes" against "use the data test"
Evidence: the end A and end B texts below alternate for the last 14 minutes. 50 of 74 pursuit_steps were not opened.
- End A, "already passes", 7 times: E44, E62, E114, E132, E198, E208, E218.
- End B, the data-test route, which prescribes the same data test: E12, E70, E110 and the L6851/L4541 texts, at E16–E22, E72–E98 and E120–E134.

Cause:
- The open's pre-run (L6750–L6760) refuses on `pre_rc == 0` even when `_passes_without_own_work` (L6032) is False, that is, when only the task's own uncommitted in-scope files make the check pass. That is the case R12 already exempted for a spawn (L6660–L6666).

Action: in examples/extensions/beagle.py:
- When the check passes only through uncommitted files in the task's scope (or its predecessor's), do not refuse. Open the task, so the close and `_prove` judge the work present: the witness takes those files away and the check must fail.
- Never prescribe a data-test done_when that already passes. Say instead that it closes on the work on disk.
- Apply the same rule to the T0151 amend refusal (L6815).
